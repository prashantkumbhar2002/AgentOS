### 2. ApprovalTicket Table - Restate Integration

Added fields for durable approval resolution:

- `restateWorkflowId` TEXT - Links approval ticket to Restate workflow
- `restatePromiseName` TEXT - Promise name for durable wait (used with ctx.promise())
- Index on `restateWorkflowId` for fast lookups

**Usage**: When an approval is needed, the workflow creates a ticket and waits on a durable promise. When a human approves/denies, the API resolves the promise using these fields.

### 3. WorkflowDefinition Table

Stores user-defined workflow configurations:

```sql
CREATE TABLE "WorkflowDefinition" (
  "id" TEXT PRIMARY KEY,
  "name" TEXT NOT NULL,
  "description" TEXT,
  "version" TEXT NOT NULL DEFAULT '1.0.0',
  "status" "WorkflowStatus" NOT NULL DEFAULT 'DRAFT',
  
  -- Workflow structure
  "definition" JSONB NOT NULL,        -- Full workflow definition (steps, etc.)
  "inputSchema" JSONB,                -- JSON Schema for input validation
  "outputSchema" JSONB,               -- JSON Schema for output
  
  -- Metadata
  "agentId" TEXT NOT NULL,
  "createdBy" TEXT NOT NULL,
  "createdAt" TIMESTAMP(3),
  "updatedAt" TIMESTAMP(3),
  "tags" TEXT[],
  
  -- Constraints
  "maxCostUsd" DECIMAL(10,4),
  "maxDurationMs" INTEGER,
  
  -- Stats
  "executionCount" INTEGER DEFAULT 0,
  "successCount" INTEGER DEFAULT 0,
  "failureCount" INTEGER DEFAULT 0
);
```

**Features**:
- Store workflows as JSON data structures
- Version control (v1.0.0, v2.0.0, etc.)
- Budget constraints (max cost, max duration)
- Execution statistics tracking
- Tag-based organization

### 4. WorkflowTrigger Table

Manages workflow execution triggers:

```sql
CREATE TABLE "WorkflowTrigger" (
  "id" TEXT PRIMARY KEY,
  "workflowDefinitionId" TEXT NOT NULL,
  "name" TEXT NOT NULL,
  "type" "TriggerType" NOT NULL,
  "enabled" BOOLEAN DEFAULT true,
  
  -- Schedule config (SCHEDULED type)
  "cronExpression" TEXT,
  "timezone" TEXT DEFAULT 'UTC',
  
  -- Webhook config (WEBHOOK type)
  "webhookSecret" TEXT,
  "webhookUrl" TEXT UNIQUE,
  
  -- Event config (EVENT type)
  "eventType" TEXT,
  "eventFilter" JSONB,
  
  -- Input config
  "defaultInput" JSONB,
  "inputOverrides" JSONB,
  
  -- Metadata
  "createdBy" TEXT NOT NULL,
  "lastTriggeredAt" TIMESTAMP(3),
  "triggerCount" INTEGER DEFAULT 0
);
```

**Trigger Types**:
1. **MANUAL**: "Trigger Now" button with form inputs
2. **SCHEDULED**: Cron-based (e.g., "0 9 * * 1" = Monday 9 AM)
3. **WEBHOOK**: External webhook URL
4. **EVENT**: React to internal events (approval completed, agent registered, etc.)

### 5. WorkflowExecution Table

Tracks individual workflow executions:

```sql
CREATE TABLE "WorkflowExecution" (
  "id" TEXT PRIMARY KEY,
  "workflowId" TEXT UNIQUE NOT NULL,  -- Restate workflow ID
  "workflowDefinitionId" TEXT NOT NULL,
  "triggerId" TEXT,
  "agentId" TEXT NOT NULL,
  "traceId" TEXT NOT NULL,
  "status" "WorkflowExecutionStatus" DEFAULT 'PENDING',
  
  -- Execution data
  "input" JSONB NOT NULL,
  "output" JSONB,
  "error" TEXT,
  "steps" JSONB,                      -- Array of step statuses
  
  -- Timing
  "startedAt" TIMESTAMP(3),
  "completedAt" TIMESTAMP(3),
  "durationMs" INTEGER,
  
  -- Cost tracking
  "totalCostUsd" DECIMAL(10,6),
  
  -- Restate integration
  "restateInvocationId" TEXT,
  "restateDeploymentId" TEXT
);
```

**Features**:
- Links to Restate invocation for live status queries
- Stores complete execution history (input, output, steps, errors)
- Duration and cost tracking
- Supports tracing via traceId
